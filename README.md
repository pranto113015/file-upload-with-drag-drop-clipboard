# File Upload with Drag & Drop, Preview & Delete Functionality

A modern **file upload UI** built with **HTML, CSS, and JavaScript**, supporting drag-and-drop, clipboard paste, image preview, and delete functionality.



## 🚀 Features

✅ **Multiple File Uploads** – Select or drag multiple files at once.  
✅ **Drag & Drop Support** – Simply drag files into the upload area.  
✅ **Clipboard Paste Support** – Paste images directly from your clipboard (`Ctrl + V`).  
✅ **Image Preview** – Instantly shows thumbnails for uploaded images.  
✅ **File Info Display** – Shows file name and formatted file size.  
✅ **Remove Option** – Easily remove any uploaded file from preview.  
✅ **Responsive Design** – Fully responsive layout with a clean dark UI.  
✅ **Built using Vanilla JavaScript** – No frameworks or dependencies (except Bootstrap for styling).



## 🧠 Project Overview

This project provides an elegant way to handle file uploads in the browser.  
Users can:
1. Click the **“+”** button to select files from their computer.
2. **Drag and drop** files directly into the upload grid.
3. **Paste** images using `Ctrl + V` (handy for screenshots).
4. Instantly **preview** images and see their file size.
5. **Remove** files they no longer need before uploading.

The layout adapts automatically for different screen sizes, thanks to Bootstrap’s grid system and custom CSS.
